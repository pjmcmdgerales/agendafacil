# AgendaFácil — protótipo GitHub Pages

Planos: Essencial R$ 49,99/mês; Pró R$ 79,99/mês.

## Publicação
1. Crie um repositório público chamado `agendafacil` no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Vá a Settings > Pages > Build and deployment; escolha Deploy from a branch, branch `main`, pasta `/(root)` e Save.
4. O site ficará normalmente em `https://SEU-USUARIO.github.io/agendafacil/`.

## Atenção
Este é apenas um protótipo de interface. Não possui autenticação, banco de dados, pagamentos ou reservas persistentes. Não use com dados pessoais reais nem venda assinaturas antes de implementar backend, segurança e testes.
